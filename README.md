🎓 Student Management System (CRUD Operations)

A full-stack web application designed to manage student records. This project demonstrates foundational CRUD (Create, Read, Update, Delete) operations using a separated frontend and backend architecture.

🚀 Features

Create: Add new student profiles to the database.

Read: Fetch and view a list of all enrolled students.

Update: Edit existing student information.

Delete: Remove student records from the system.

Separated Architecture: Cleanly divided into a client-side frontend and a server-side backend.

🛠️ Tech Stack

Frontend:

React (via Vite)

JavaScript / JSX

CSS for styling

Backend:

Node.js

Express.js

MySQL

⚙️ Installation and Local Setup

To run this project locally, you will need to start both the backend server and the frontend development environment.

1. Clone the repository

git clone https://github.com/Tanmay-Srivastavaa/CRUD-Basic-Operations.git
cd CRUD-Basic-Operations


2. Backend Setup

Navigate to the backend directory, install dependencies, and start the server:

cd Backend
npm install
npm start 
# or 'node index.js' depending on your package.json scripts


(Note: If your backend requires environment variables for a database connection, create a .env file here and add your credentials before starting the server.)

3. Frontend Setup

Open a new terminal window/tab, navigate to the frontend directory, install dependencies, and run the Vite development server:

cd Frontend
npm install
npm run dev


The frontend will typically run on http://localhost:5173/, and it will communicate with your backend server.
